---
title: Cursor CLI in h0x-ADE
---

Cursor CLI is Cursor's command-line agent. h0x-ADE runs it with first-class support — launch from the combobox, full OSC state detection, and restart chip on exit.

## Setup

1. Install Cursor CLI per [Cursor's docs](https://cursor.com/cli).
1. Log in once.
1. h0x-ADE auto-detects the CLI on `PATH`.

## Launching

Pick **Cursor** from the combobox. h0x-ADE launches the CLI scoped to the worktree. Cursor's TUI emits the state events h0x-ADE needs for agent state dots.

## Model selection

Model selection is driven by Cursor's own settings. h0x-ADE doesn't override it — configure inside the CLI.
