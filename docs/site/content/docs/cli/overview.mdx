The h0x CLI is the `orca` command-line interface for scripting a running h0x-ADE editor from any shell. Use it to create and inspect worktrees, drive agent terminals, open files and diffs, automate the built-in browser, run scheduled automations, share HTML/Markdown artifacts, and control h0x-ADE-native tools from scripts or AI agents.

It ships with the desktop app; register it under [Settings → General → h0x CLI](/docs/settings). The command is `h0x` on every supported platform.

Agents can install the matching h0x CLI skill with:

```bash
npx skills add https://github.com/vjk7989/h0x-ade --skill orca-cli
# headless / no Settings UI:
h0x skills install --skill orca-cli
```

See [Skills registry & MCP](/docs/cli/skills) for every installable h0x-ADE skill, including `h0x skills install` / `h0x skills update`.

## Install & verify

```
command -v
h0x status --json
```

## Worktree commands

```
h0x worktree ps --json
h0x worktree create --repo id:<repoId> --name my-task --issue 123 --json
h0x worktree current --json
h0x worktree set --worktree active --comment "reproduced bug" --json
h0x worktree rm --worktree id:<id> --force --json
```

For selectors, setup flags, parent/child worktrees, and the broader command map, see [h0x CLI reference](/docs/cli/reference).

## Terminal commands

```
h0x terminal list --json
h0x terminal read --json
h0x terminal send --text "continue" --enter --json
h0x terminal wait --for tui-idle --timeout-ms 30000 --json
h0x terminal create --worktree path:/projects/app --command "npm test" --json
h0x terminal split --direction vertical --command "npm run dev" --json
```

For tracked multi-agent work, use [Orchestration](/docs/cli/orchestration) instead of plain terminal prompts.

## File commands

Open files and diffs in the active h0x-ADE worktree from a shell:

```
 file open src/App.tsx
 file diff src/App.tsx --staged
 file open-changed --mode both
```

Use `--worktree <selector>` when the shell's current directory is not inside the target worktree.

## Browser profiles

Browser profiles isolate tab session state, so a script or agent can test with different cookies, local storage, and logged-in identities. The CLI exposes profile commands under `h0x tab profile`; start with `h0x tab profile list --json`, then use `create`, `set`, `clone`, or `use-default` as needed.

## Scheduled automations

Use `h0x automations` to create, inspect, run, and remove scheduled h0x-ADE tasks from a shell. Start with [Scheduled automations](/docs/cli/automations) when you want a recurring prompt to run against a repo or an existing worktree.

## Artifacts

Share HTML or Markdown as public view links through the signed-in h0x-ADE account (`h0x artifacts share|update|list|delete`). Publishing is **opt-in** under Settings → Artifacts. Command details: [CLI reference → Artifacts](/docs/cli/reference#artifacts).

## Browser automation

The CLI also drives the built-in browser with a snapshot-interact-re-snapshot loop:

```
h0x goto --url https://example.com --json
h0x snapshot --json     # returns refs like @e1, @e3
h0x click --element @e3 --json
h0x fill --element @e1 --value "user@example.com" --json
h0x screenshot --json
```

For responsive browser checks, switch the active tab to a named device profile:

```
 set device --name "iPhone 12" --json
h0x screenshot --json
```

## Mobile emulator

The CLI can also drive an iOS Simulator through h0x-ADE's mobile emulator bridge. It is scoped to the active worktree, so agents and scripts can attach a simulator from `h0x emulator list`, tap normalized coordinates, type text, send gestures, rotate the device, and shut it down without leaving h0x-ADE.

```
h0x emulator list --json
h0x emulator attach "<device-name-or-udid>" --json
h0x emulator tap 0.5 0.7 --json
h0x emulator type "hello" --json
h0x emulator gesture '[{"type":"begin","x":0.5,"y":0.8},{"type":"move","x":0.5,"y":0.4},{"type":"end","x":0.5,"y":0.2}]' --json
h0x emulator rotate landscape_left --json
h0x emulator kill --json
```

Use `--worktree <selector>`, `--device <udid-or-name>`, or `--emulator <id>` when a script needs an explicit target.
